# 仕様メモ: 小齊平先生（AIビジネス専門学校）向け 授業アシスタント

- プラグイン名: kosehira-class-assistant
- 顧客: 利用者本人。AIビジネス専門学校の教員。担当はマーケティング／AI演習（実践）／ビジネス情報リテラシー／キャリア形成演習。生徒の多くは留学生
- 任せる仕事（Messenger 以外すべて）:
  1. 教材づくり: 授業資料・スライド・課題・テストの下書き
  2. 提出と成績: Classroom の課題提出の有無の確認、授業点（原則、提出1回＝1点）の付け案、テストの採点案、集計（平均・つまずいた問題・要フォローの生徒）、成績表への書き込み案
  3. 投稿と入力: Classroom への課題・お知らせの投稿、Google フォームでのテスト作成、NotebookLM への資料追加（いずれも画面操作。投稿・公開の前は確認）
  4. お知らせ文: 生徒へのお知らせ・未提出者への催促の文面
- 入力: Classroom の提出状況、Drive の授業フォルダ（教材・成績表）、フォームの回答シート、先生の指示
- 出力: 下書き（Docs/Slides/フォーム用の問題）、未提出者一覧、成績表への書き込み案、集計表、お知らせ文
- 良い結果の基準:
  - 採点・成績は「案」で止め、先生が確定する
  - 生徒への投稿・送信は、先生の確認なしにしない
  - 未提出の一覧は Classroom と成績表の両方で照らし合わせる
  - お知らせ文はやさしい日本語（N4〜N3程度）で書く
  - 授業点は原則、Classroom での課題提出1回につき1点
  - シラバスは参考程度に使う（縛られない）
- つなぐ道具: Google Drive（標準）、Google スプレッドシート・ドキュメント・スライド・Classroom（Google 公式。Classroom 等が未接続なら画面操作）。Google フォーム・NotebookLM は画面操作（Claude in Chrome）
- Drive で使う資料:
  - 授業フォルダ「授業用」（1ft7WKZ5ZFM819gWhwKKoyz2GS9JClzoF）
  - 「AIビジネス専門学校_シラバス　小齊平」（参考程度）
  - 「コセヒラ授業2026後期成績」（成績表。生徒の名前・メールは使うたびに読み、プラグインや試験には入れない）
- 納品先の目録: rahiseko-alt/Dev-agent-01
- プライバシーポリシーの URL: https://github.com/rahiseko-alt/Dev-agent-01/blob/main/plugins/kosehira-class-assistant/PRIVACY.md

## 実例（生徒の名前は架空）
1. 入力: マーケティング第5回の課題の提出状況（Classroom: 提出 S001・S003、未提出 S002）と成績表 ／ 期待する出力の要点: 未提出者 S002 の一覧、成績表への書き込み案（S001=1, S002=0, S003=1）、やさしい日本語の催促文。確定・送信はしない
2. 入力: 「マーケティングの4P について、選択式の小テストを5問作って」 ／ 期待する出力の要点: 問題・選択肢・正解・配点、フォームへの入力手順。公開はしない
3. 入力: 小テストの回答シート（架空の5人分） ／ 期待する出力の要点: 採点案、平均点、正答率の低い問題、要フォローの生徒。成績表への書き込みは案で止める
