# 仕様メモ: 学校法人海鵬学園 AIビジネス専門学校 向け 高校訪問の報告・お礼メール作成

- プラグイン名: kaiho-visit-followup
- 顧客: 学校法人海鵬学園 AIビジネス専門学校（名古屋、2026年4月開校）。使うのは高校を回る募集担当（営業担当）
- 任せる仕事: 高校訪問の後に、上司向けの訪問報告書と、進路指導の先生宛てのお礼メールの下書きを作る
- 入力: 訪問後に担当者が残す箇条書きメモ（手入力か、話した言葉を文字にして貼り付け）。先生の質問と、その場での回答を含む
- 出力:
  1. 上司向け訪問報告書: 訪問校／日付／面談した先生／話した内容／先生の反応／次の約束／次にやること（期日つき）／持ち帰りの確認事項
  2. 先生宛てお礼メール下書き: 件名／宛名（〇〇先生）／訪問のお礼／話に出た話題への言及／資料やオープンキャンパスの案内／持ち帰った質問は「確認のうえ改めてご連絡いたします」／次の連絡の予告／署名
- 良い結果の基準:
  - メモに無いことを書き足さない
  - 報告書に「次にやること」を期日つきで必ず入れる
  - お礼メールは宛名に「先生」を付け、話に出た話題に必ず触れる
  - 入学を強く押す言い方をしない
  - 学費・定員・入試・就職実績など「統一回答のみ」の項目は、Drive の統一回答の文言から外れない。統一回答が「保留」または無い項目は答えず「確認のうえ改めてご連絡いたします」と書く
- つなぐ道具: Google Drive（標準）
- Drive で使う資料:
  - 「AIビジネス専門学校_高校訪問想定質問_小斉平追記版」（統一回答の一覧。メールで学校の説明をするときの唯一の根拠）
  - 「海鵬様＿高校訪問調査リスト＿V1.xlsx」（訪問先の高校の特徴と過去の訪問メモ。報告書の背景に使う）

## 実例（Drive の訪問記録より。先生の名前は伏せた）
1. 若宮商業高校（〇〇先生）訪問メモ: 進学先は美容・デザイン系が多く、ビジネス系はそこまで多くない／パイプのある専門学校は無い／進学先は夏休み明け〜秋に決まり、候補は夏休み前に決まる／夏休み前のオープンキャンパスがあるとよい→実施できるようにしていく／日本人枠の拡大見込み→前向きに検討／AI設備→PCを支給予定
   期待する出力の要点: 報告書に「夏休み前のオープンキャンパス日程を先生へ連絡（期日つき）」が入る。メールで夏休み前のオープンキャンパスに触れ、PCは「1人1台支給」の統一回答どおり
2. 中川青和高校（〇〇先生）訪問メモ: 留学生の日本語レベルの質問→見聞きはできるレベルと回答／4月入学の日本人の出身校（普通科か商業科か）の質問→普通科が多いと回答／日本人59名の男女比→男子がやや多いと回答／留学生の日本語授業の場所→本校
   期待する出力の要点: 統一回答では「日本人学生は現在0人」「留学生の日本語力はN3程度を想定」なので、その場の回答と食い違う点を報告書の「持ち帰りの確認事項」に挙げ、メールでは統一回答の文言だけを使う（その場の誤った回答を繰り返さない）
3. 春日井泉高校（〇〇先生、英語の先生）訪問メモ: 家政コースからも受験できるか→できる／英語はどのくらいを目指すか→ビジネスで使えるレベル（苦手な子には厳しいかもとのコメント）／2年目の学費→初年度より少し高くなると回答／愛専各に入るか→入る予定と回答／コース名の確認
   期待する出力の要点: 英語の目標は統一回答が「保留」なので、メールでは答えず「確認のうえ改めてご連絡いたします」。2年目の学費は統一回答（年間880,000円＋教材費約100,000円）に沿い、その場の「少し高くなる」は報告書で要確認に挙げる。愛専各は「加入しています」
