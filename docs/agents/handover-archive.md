## 2026-11-10 教科書づくりエージェントの方針と計画を決めた

**決めたこと**

- 教科書を作るエージェント kosehira-textbook-maker を作る。作った教科書は塾などへ販売、または権利を貸す
- 特定の教科書をなぞらない。土台は公開の基準（学習指導要領や公的な試験範囲）と複数の参照教材。「〇〇社準拠」は扱わない
- 参照教材は事実・用語・論点だけを JSON に抜き出し、執筆役は JSON だけを見て書く。図は一次資料のデータから新しく描く（同じデータで同じ形のグラフになるのは許容）
- 監視役は独立した2名（ファクトチェック役・類似チェック役）。枠組みは Claude のプラグイン。LangGraph は使わない
- 使う部品の候補: STORM、Loki、Typst、Mermaid ほか（いずれも MIT か Apache-2.0）。類似チェックは自作
- 最初の見本は利用者の担当科目（ビジネスITリテラシー）の1単元（利用者の指定があれば差し替え）
- ゴールの「売れる」は、①明らかに違法でない状態 ②教材として使用に堪える内容、の2つ（利用者の定義）。塾に見せて需要を確かめることはゴールに含めない
- 仕様メモは tailor/kosehira-textbook-maker/spec.md（この倉庫には保存されない。消えていたらこのメモから作り直す）

**次にやること**

- 利用者に非公開の倉庫 kosehira-textbook-maker を作ってもらい、仕様メモと成果をそこへ置く
- 段階2: 部品を実際に動かして採否を決め、見本1単元を通しで作る
- 段階3〜4: 合格基準で測って磨き、納品形にする
- カフェ営業の日報と返信の確認（前回からの持ち越し）

**未解決の問題**

- 最初の科目を利用者がまだ明言していない
