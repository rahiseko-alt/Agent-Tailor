## 2026-11-04 この置き場所のどの会話でも Agent Tailor が使える

**決めたこと**

- Agent Tailor は `.claude/skills/make-sellable-agent` から参照し、この置き場所で会話を始めれば「〇〇のエージェントを作って」で動く（クラウド上の会話は設定で有効にしたプラグインを読まないため）
