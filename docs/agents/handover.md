## 2026-11-26 プロジェクションマッピングのエージェントを作った（rahiseko-alt/projection-mapping）

**決めたこと**

- 利用者の個人制作「意思を持つ光」を rahiseko-alt/projection-mapping に作った（公開・利用者の指定）。Windows・CPU だけで動く。Ollama・クラウド GPU は使わない（クラウド GPU は手元で確実に動いてから上乗せを検討）

- 振り返りを Google Drive に残すなら、置き場所のフォルダを利用者に確かめる

**未解決の問題**

- 個人で使う範囲でログインを使ってよいかの規約上の確証は無い
- 作業フォルダ tailor/self-projection-mapping/ は手元にしか無い（.gitignore 済み）。仕様メモの要点は projection-mapping の README に入っている
