# プライバシーについて

教科書づくり（kosehira-textbook-maker）は、自分では何も集めず、どこにも送りません。

- 参照教材や作った教科書を、このプラグインの作者や第三者へ送ることはありません。
- Google Drive につないだときは、利用者が置いた参照教材・シラバスのひな型を読み、作った教科書と記録を利用者の Drive に保存します。共有・移動・削除は、利用者に確かめてから行います。
- 事実確認のために Web を検索します。検索語に参照教材の本文や個人の情報は入れません。
- Google Drive の扱いは、Google のプライバシーポリシーに従います: https://policies.google.com/privacy
- Claude 自体の扱いは、Anthropic のプライバシーポリシーに従います: https://www.anthropic.com/legal/privacy
- パスワードや鍵は、このプラグインには入っていません。Drive へのサインインは Claude の接続設定で行います。
