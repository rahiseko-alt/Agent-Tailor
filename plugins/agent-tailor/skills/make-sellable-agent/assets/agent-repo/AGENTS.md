# AGENTS.md（〔エージェント名〕の置き場所）

この置き場所には、Agent Tailor が作ったエージェント〔エージェント名〕の本体（plugins/）と、その仕事の成果物が入る。
利用者は非エンジニア。専門用語を使わず、結論から短く話す。

## 会話の始めと終わり

- 最初の応答の冒頭で `s` を起動する。利用者が「s」「開始」「はじめ」「始め」「start」とだけ送ったときも起動する。
- 利用者が「f」「終了」「おわり」「終わり」とだけ送ったら `f` を起動する。
- 引き継ぎメモ（docs/agent/handover.md）は、何かを提出したとき・方針を決めたときに一番上へ1件足し、
  `sh .claude/hooks/handover-trim.sh` で件数を整えて、すぐコミットして送る。
- 次の会話は本番の版（main）のメモを読むので、`f` では必ず本番の版まで入れる。
