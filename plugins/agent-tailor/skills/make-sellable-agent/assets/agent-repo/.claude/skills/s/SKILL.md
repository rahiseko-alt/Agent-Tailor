# s — 会話の始め

1. 読むだけで調べる（書き込まない）
   - `docs/agent/handover.md` の一番上の1件（前回の「次にやること」「未解決の問題」）
   - `git status --short --branch`（未保存の変更）と、送っていない記録（`git log origin/<枝>..HEAD`）
   - 提出中の変更（GitHub の MCP ツールで、開いている PR）。確かめられなかったら「確認できませんでした」と書く
2. 次の3点だけを、この順で短く報告する。表は使わない
   - **前回の続き**: 残っている作業を1〜2行。無ければ「ありません」
   - **いまの状態**: 未保存／未送信／提出中 の有無を1行
   - **最初の一手**: 1つだけ。利用者の操作が要るならその手順
3. 報告したら止まり、利用者の指示を待つ。2回目以降は自動で出さない
