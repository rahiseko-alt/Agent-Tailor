# f — 会話の終わり

満たしていない項目は、まず自分で満たしにいく。確かめられなかったことを「問題なし」と読み替えない。1つでも満たせなければ「終了できません」と言い、理由と直し方を書く。

1. **未保存の変更がゼロ**: `git status --porcelain` が空。空でなければ中身を見てコミットする
2. **未送信がゼロ**: `git ls-remote --heads origin <枝>` の版が手元の `git rev-parse HEAD` と同じ。違えば `git push -u origin <枝>`
3. **引き継ぎメモに今回の内容がある**: 提出した物・決めた方針があれば `docs/agent/handover.md` の一番上に1件足し、`sh .claude/hooks/handover-trim.sh` を流してコミット・送信。何も無い会話では書かない
4. **引き継ぎメモが本番の版（main）に入っている**: 次の会話は本番の版を読む。
   `git fetch origin main && git diff --quiet origin/main HEAD -- docs/agent/handover.md docs/agent/handover-archive.md` が成功すれば反映済み。
   そうでなければ、origin/main から新しい枝を作り、メモの2ファイルだけを作業の枝から持ってきてコミット・送信し、PR を作って本番に取り込む（確認は要らない）。元の枝に戻る
5. **提出中の変更を明示**: 開いている PR の番号・題名を書く。メモ以外の PR を本番に入れるかは、一度だけ尋ねる。勝手に入れない

すべて満たしたら、次の形で報告する:

> **終了して問題ありません。** 作業環境を消しても、失われるものはありません。
> - 未保存の変更: なし ／ 未送信: なし ／ 引き継ぎメモ: 記録済み・本番の版に反映済み ／ 提出中の変更: 〔なし／#番号〕
> 次回は「s」か「開始」と打てば、続きから再開できます。
