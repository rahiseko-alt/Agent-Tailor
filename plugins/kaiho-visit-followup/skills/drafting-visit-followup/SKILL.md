# 高校訪問の報告書とお礼メールを作る

訪問後の箇条書きメモ（先生の質問と、その場での回答を含む）から、2つの下書きを作る。
1. 上司向け訪問報告書
2. 進路指導の先生宛てお礼メール

## 手順

1. Google Drive で、次の資料を探して読む。つながっていなければ、利用者が貼り付けた資料で進める。貼り付けも無ければ、学校の説明は書かず、その旨を最後に伝える。
   - 「AIビジネス専門学校_高校訪問想定質問_小斉平追記版」（統一回答の一覧。メールで学校を説明するときの唯一の根拠）
   - 「海鵬様＿高校訪問調査リスト＿V1.xlsx」（訪問先の高校の特徴と過去の訪問メモ。報告書の背景に使う）
   - Drive のファイルを共有・移動・削除する操作はしない。必要なら先に利用者へ確かめる。
2. 訪問メモを読み、次を拾い出す: 訪問校・日付・面談した先生・話題・先生の質問とその場の回答・先生の反応・約束・持ち帰り事項。
3. メモの質問ごとに、統一回答と照らす（`references/answer-rules.md`）。
4. 報告書を作る（形は `references/formats.md`）。
5. お礼メールを作る（形は `references/formats.md`）。
6. 確認して直す（下の「確認項目」）。直してから出す。

## 良い結果の基準

- メモに無いことを書き足さない。日付・先生名などが無ければ「未記入（要確認）」とする。
- 報告書に「次にやること」を、期日つきで必ず入れる。メモにある約束・要望（例:「〜できるようにしていく」「〜を検討」）は、すべて「次にやること」の項目にする。期日がメモに無いときは、空欄にせず「訪問日から1週間以内」「訪問日の翌週末まで」のように、すぐ使える期日の案を書く（「◯月◯日」だけの空欄は期日とみなさない）。
- お礼メールは宛名に「先生」を付け、話に出た話題に必ず触れる。
- 入学を強く押す言い方をしない。
- 学費・定員・入試・就職実績・設備・学生数・日本語力など「統一回答のみ」の項目は、統一回答の文言から外れない。
- 統一回答が「保留」または無い項目は、メールで答えず「確認のうえ改めてご連絡いたします」と書く。
- その場の回答が統一回答と食い違うときは、報告書の「持ち帰りの確認事項」に挙げる。メールには、その場の回答を繰り返さず、統一回答の文言だけを使う。

## 確認項目

- 報告書に、期日つきの「次にやること」があるか。
- メールの宛名が「〇〇先生」か。話題に触れているか。
- メールの数字・名称が、統一回答と一字違わないか。
- メモに無い約束や数字を足していないか。
- 食い違いが、すべて報告書の確認事項に載っているか。

## 出力

報告書、メールの順に、そのまま貼れる形で、**最後の返答の本文に全文を書く**（ファイルに保存しただけで終わらない）。最後に「要確認」を数行でまとめる。
