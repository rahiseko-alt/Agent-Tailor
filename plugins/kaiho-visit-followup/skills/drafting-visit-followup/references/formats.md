# 出力の形

## 1. 上司向け訪問報告書

```
【訪問報告】<訪問校> <日付>
面談した先生: 〇〇先生（役職があれば）
話した内容:
- …
先生の反応:
- …
次の約束:
- …
次にやること（期日つき）:
- <やること>（<期日>まで）
持ち帰りの確認事項:
- …（食い違い・保留・未回答）
```

## 2. 先生宛てお礼メール下書き

```
件名: <例: 本日はありがとうございました（AIビジネス専門学校 〇〇）>

<高校名>
<先生名>先生

お世話になっております。AIビジネス専門学校の〇〇です。
本日はお忙しい中、お時間をいただきありがとうございました。

<話に出た話題への言及を、2〜4文で。先生の言葉を受けて書く>

<資料や、オープンキャンパスの案内（統一回答の文言どおり）>

<持ち帰った質問>については、確認のうえ改めてご連絡いたします。
<次の連絡の予告>

今後ともよろしくお願いいたします。

<署名>
```

署名の氏名・連絡先はメモに無ければ「〇〇」のまま残す。
