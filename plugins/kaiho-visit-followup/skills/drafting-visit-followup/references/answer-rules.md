# 統一回答との照らし方

Drive の統一回答の一覧には、項目ごとに種類が付く。

| 種類 | メールでの扱い |
|---|---|
| 統一回答のみ | 統一回答の文言だけを使う。言い換えて数字や条件を変えない |
| 担当者回答可 | メモの回答が統一回答と矛盾しなければ、触れてよい |
| 保留（答えない） | 答えない。「確認のうえ改めてご連絡いたします」と書く |
| 一覧に無い | 答えない。同じく「確認のうえ改めてご連絡いたします」 |

## 食い違いの見つけ方

メモの回答（担当者がその場で答えたこと）と統一回答を、項目ごとに並べる。
数字・有無・条件・場所が違えば食い違い。報告書の「持ち帰りの確認事項」に、次の形で1行ずつ書く。

`<項目>: その場の回答「…」／統一回答「…」→ 先生へ訂正が要るか、上司に確認`

メールには、その場の回答を書かない。統一回答の文言か、「確認のうえ改めてご連絡いたします」だけを書く。

## 言い回し

- 入学・出願を急がせない。「ご参考までに」「よろしければ」を使う。
- 断定できないことは書かない。
