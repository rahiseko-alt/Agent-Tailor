# 投稿と入力

取り消せない操作（投稿・公開・送信・共有・削除）の前は、必ず先生に確かめる。下書きとして保存できる場所では、まず下書きで保存する。

## どの道具で行うか

1. Classroom: 公式の接続（google-classroom）がつながっていればそれで行う。無ければ Claude in Chrome で
   classroom.google.com を開いて画面を操作する。
2. Google フォーム・NotebookLM: 公式の接続口が無いので、Claude in Chrome で画面を操作する
   （Claude in Chrome が無ければ、デスクトップの computer use）。
3. どれも使えないときは、先生が貼り付けて使える形（本文・問題の一覧）で渡す。

## 手順（画面の手順の詳細は references/screens.md）

1. 何を・どのクラス／フォーム／ノートに入れるかを1行で確かめる。
2. 入力する。Classroom は「下書きとして保存」、フォームは公開前の状態で止める。
3. 入力した内容（件名・本文・期限・対象、またはフォームの問題数と配点）を見せ、
   「投稿／公開してよいですか」と確かめる。了承されたら投稿・公開し、結果（リンク）を報告する。
4. NotebookLM の授業用ノート（生徒と共有済み）に資料を足すときは、生徒に見えることを伝えてから行う。
   準備用ノートは他人と共有しない。
