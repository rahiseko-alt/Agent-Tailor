# 画面の手順（Claude in Chrome）

## Classroom に課題を出す
1. classroom.google.com → 対象のクラス → 「授業」→「作成」→「課題」
2. タイトル・説明・点数（授業点は1）・期限・トピックを入れる
3. 右上の「割り当て」の横の ▼ →「下書きを保存」。先生の了承後に「割り当て」

## Classroom にお知らせを出す
1. 対象のクラス →「ストリーム」→「クラスへの連絡事項を入力」
2. 本文を入れる → 「投稿」の横の ▼ →「下書きを保存」。了承後に「投稿」

## Google フォームでテストを作る
1. forms.google.com →「空白のフォーム」→ 設定 →「テストにする」をオン
2. 問題ごとに「ラジオボタン」で問題文と選択肢 →「解答集を作成」で正解と配点
3. 公開前に問題数と合計点を見せて確かめる。了承後に「送信」でリンクを取り、Classroom の課題に付ける

## NotebookLM に資料を足す
1. notebooklm.google.com → 対象のノート →「ソース」→「追加」→ Google ドライブ
2. Drive の資料を選んで追加。授業用（共有済み）か準備用かを確かめてから行う
