# 教材づくり

出すのは下書き。仕上げと公開は先生が行う。

## 手順

1. **日付から授業を特定する**: 「明日」「〇日」の授業なら、曜日と時間割から科目を決め、第何回かを決める。
   決められなければ、先生に1問だけ聞く（推奨の答えを添える）。
2. **準備用のノートブックを見る（いちばんの根拠）**: Claude in Chrome（無ければデスクトップの computer use）で
   NotebookLM の準備用ノートを開き、その回のソースと、最新の作り方を本文と画面の両方で見る。
   - 準備用ノート（他人と共有していない）: https://notebooklm.link.google/C4GE5ls2GnuN 、 https://notebooklm.link.google/MuJqYxh6ldzU
   - 授業用ノート（生徒と共有済み）: https://notebooklm.link.google/la5wydepchDS 。資料を足すのは先生の確認後
   - 作り方は最近変わっている。Drive の古い資料やシラバスから作り方を推し量らない（先生の指示）
   - ノートブックを開けない（クラウド上の会話など）ときは、そう伝えて止まり、パソコンの Claude で開くか、ソースを貼ってもらう
3. 作る（ノートブックの作り方とお手本に合わせる。無いときだけ references/templates.md）:
   - 授業資料: Google ドキュメントの下書き（google-docs）。見出し・要点・例・確認の問い
   - スライド: Google スライドの下書き（google-slides）。1枚1メッセージ、10枚前後
   - 課題: 目的・やること・提出物・期限・評価の観点
   - テスト: 1問ごとに問題・選択肢・正解・配点・解説（必ず全問に付ける）。選択式は正解が1つに決まるようにする。最後に「フォームに入力しますか」と確かめる
4. 留学生向けに、指示文はやさしい日本語で書く（writing-student-notices の決まりと同じ）。
5. 下書きを Drive のどのフォルダに置くか確かめてから保存する。フォームへの入力・Classroom への投稿は posting-to-class-tools で行う。
6. 見直す: 正解が1つに決まるか、指示があいまいでないか、時間内に終わる量かを確かめてから見せる。
