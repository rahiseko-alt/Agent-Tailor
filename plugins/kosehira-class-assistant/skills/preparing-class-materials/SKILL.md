# 教材づくり

出すのは下書き。仕上げと公開は先生が行う。

## 手順

1. 材料を集める: Google Drive の授業フォルダ（「授業用」）で、科目と回に関係する資料・教科書の抜粋・過去の課題を探して読む。
   シラバス「AIビジネス専門学校_シラバス　小齊平」は参考程度に見る（縛られない）。先生の指示を一番優先する。
2. 作る（形は references/templates.md）:
   - 授業資料: Google ドキュメントの下書き（google-docs）。見出し・要点・例・確認の問い
   - スライド: Google スライドの下書き（google-slides）。1枚1メッセージ、10枚前後
   - 課題: 目的・やること・提出物・期限・評価の観点
   - テスト: 1問ごとに問題・選択肢・正解・配点・解説（必ず全問に付ける）。選択式は正解が1つに決まるようにする。最後に「フォームに入力しますか」と確かめる
3. 留学生向けに、指示文はやさしい日本語で書く（writing-student-notices の決まりと同じ）。
4. 下書きを Drive のどのフォルダに置くか確かめてから保存する。フォームへの入力・Classroom への投稿は posting-to-class-tools で行う。
5. 見直す: 正解が1つに決まるか、指示があいまいでないか、時間内に終わる量かを確かめてから見せる。
