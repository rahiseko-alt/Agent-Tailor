# 生徒へのお知らせ

生徒の多くは留学生。やさしい日本語で、短く、何をいつまでにするかをはっきり書く。

## 手順

1. 目的を決める: 催促／テストの案内／予定の変更／その他。対象（全員・未提出者など）と期限を確かめる。
   未提出者への催促なら、tracking-submissions-and-grades の結果を使う。
2. 書く（references/easy-japanese.md の決まりに従う）:
   - 1文は短く。むずかしい漢字にはふりがなを（ ）で付ける
   - 「何を」「いつまでに」「どこで（Classroom のどこ）」を必ず入れる
   - 責める言い方をしない。「まだ出していない人は、出してください」のように書く
3. 見せる: 件名と本文、対象の人数を見せ、「Classroom に投稿しますか」と確かめる。
   投稿は posting-to-class-tools で行う。先生の了承なしに投稿・送信しない。
