# やさしい日本語の決まり

- 1文に1つのことだけ書く。1文は40字以内を目安にする
- 二重否定・受け身・敬語の重ねを使わない（「ご提出いただけますようお願い申し上げます」→「出してください」）
- 日付は「11月10日（火）17:00まで」の形
- 漢字は小学校で習う程度まで。それ以外は（ ）でふりがな、または ひらがな
- 最後に「わからないときは、先生に聞いてください。」を付ける

見本:
```
件名: 第5回の課題を出してください

マーケティングの第5回の課題を、まだ出していない人がいます。
11月10日（火）17:00までに、Classroom の「課題」から出してください。
わからないときは、先生に聞いてください。
```
